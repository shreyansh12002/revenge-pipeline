Story Workflow

How should stories move through the app?

A

Linear Pipeline

Scrape → Filter → Generate Script → Generate YouTube Package → Export

One-way flow, clear steps, guided journey

B

Hub & Spoke

Stories are central hub. Generate scripts, YouTube packages, or export from any story independently.

Flexible, non-linear, better for revisits

C

Kanban Board

Stories in columns: Raw | Scripted | Packaged | Exported

Visual, great for batch workflows, gaming-style progress
